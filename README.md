# Развитие и потенциал

Портфолио: сайтове за малкия бизнес в Стара Загора. Обикновен HTML и CSS, без инсталиране и без build. Публикува се с GitHub Pages директно от това хранилище.

- `index.html`, `styles.css`: портфолиото.
- `assets/`: снимки на екрана на проектите.

Нов проект: снимки на екрана в `assets/` и нова карта в секция „Работа“ в `index.html`.
